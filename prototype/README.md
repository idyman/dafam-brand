# Da Fam · clickable prototype

A clickable Hebrew (RTL) prototype of the Da Fam January beta: splash, onboarding, and the main app (Today, Calendar, Chores, Family, voice add, quick add, event detail).

Open `index.html` in any browser, or visit the GitHub Pages link. On a desktop it shows inside a phone frame; on a phone it fills the screen.

## Flow

Splash → Welcome → Create household → Invite partner → Connect calendar → Notifications → Today

Everything is clickable: tick items, claim responsibilities ("שלי"), filter chores, switch the calendar between day and week, try shopping mode, confirm a pickup, and add a family cover photo (it stays on your device).

## Notes

- Sample data only (the Levi family). Nothing is saved or sent anywhere; reloading resets it.
- The invite link and calendar connection are simulated.
- Built with plain HTML, CSS and JavaScript. No build step.
